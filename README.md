## 数据与口径

- **数据源**：中证指数官网（csindex.com.cn）官方日线，全收益指数（含分红再投资），价格指数用于股息率价差法
- **定投规则**：每月首个交易日按收盘价买入 10,000 元，2016-07 至 2026-07，121 期，总投入 ¥1,210,000，未计费用
- **年化**：XIRR（资金时间价值口径）
- **组合市值回撤**：每日（累计份额 × 指数点位）从峰值回落的最大幅度；恢复日＝首次收复峰值
- **当前股息率**：近 12 个月分红收益率（全收益与价格指数日收益差，价差法），与 Wind TTM 交叉验证一致
- **年度涨跌幅**：全收益口径，2016 年为定投起点（2016-07-01）至年末，其余年份为自然年

## 文件结构

```
dividend/
├── dividend_dashboard.html   # 最终网页(单文件, ECharts CDN)
├── publish/index.html        # 部署版本(与上相同)
├── backtest.py               # 定投回测 + 回撤计算 → result.json
├── calc_dividend.py          # 股息率价差法 → dividend_yield.json
├── check_logic.py            # 独立交叉验证(期数/终值/XIRR/股息率/恢复日)
├── generate_html.py          # 生成网页(读 result.json + dividend_yield.json)
├── fetch_retry.py            # 拉取指数日线(串行+重试)
├── H*.json / price_*.json    # 官方日线缓存(全收益/价格)
└── result.json               # 回测结果(含绘图序列)
```

## 复现

```bash
python backtest.py          # 重跑回测(可改 AMOUNT/起始年)
python calc_dividend.py     # 算股息率
python generate_html.py     # 重新生成网页
python check_logic.py       # 独立验证核心数字
```
